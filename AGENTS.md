# Repository working rules

- Read `PROGRESS.md` before modifying this repository, and read `context.md` for current user requirements.
- Before ending a substantial session, update `PROGRESS.md` with completed work, verification results, blockers, current artifact versions, and exact next steps.
- Keep `context.md` current when requirements or decisions change. Distinguish measured results from historical reports and unverified expectations.
- Preserve existing history, frozen benchmarks, and server-side secrets. Never put private credentials in source, logs, documentation, or the APK.
